# My Linux Scripts
Some small Bash scripts I’m making while learning Linux. I’m very new to coding, so I’m starting with stuff I actually use on my CachyOS PC.
## Scripts
### sysup
Updates my system packages with pacman and AUR packages with paru.
### temps
Shows my CPU and GPU temperatures and how much space is left on my system and games drives.
### tidy
Sorts files in my Downloads folder by file type.
Running `tidy` previews what would move, and `tidy --go` moves the files.
It skips files if the same name already exists at the destination.
